# BloodLine

12の質問から、回答者に流れる吸血鬼の血族を鑑定する静的Webサイトです。

## 構成

- `index.html`: 画面構造とメタ情報
- `styles.css`: PC・スマートフォン対応のデザイン
- `script.js`: 質問、診断ロジック、結果表示、X共有
- `assets/characters/`: 10血族の紙人形キャラクター画像

トップ画面と結果画面から10血族の一覧を閲覧でき、各キャラクターを選ぶと個別結果へ移動できます。

## ローカル確認

ファイルを直接開くか、任意の静的Webサーバーでルートディレクトリを配信してください。

```sh
python3 -m http.server 8000
```

## 公開

GitHub Pagesで、リポジトリのルートを公開元に設定する想定です。
